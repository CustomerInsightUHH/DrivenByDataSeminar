# Driven by Data Seminar

This folder contains the course materials for the **Driven by Data** seminar.

## Contents

### AI Coding Introduction (`AI_Coding_Introduction.ipynb`)
This notebook is **mandatory** for all participants. Work through it first to get up to speed with advanced Python coding before moving on to the seminar projects.

### Trial Racing Dataset (`Trial_Racing_Dataset/`)
A dataset for exploring and testing your first ideas. Use this to experiment and get familiar with the data before working with the real racing data.

### Race Team Notebook (`Race_Team_Project_Notebook.ipynb`)
The main notebook for group work in the **second month** of the seminar. This is where your team will collaborate on the actual racing analysis project.

## Getting Started

1. Complete the **AI Coding Introduction** notebook
2. Explore the **Trial Racing Dataset** to develop and test ideas
3. Begin the **Race Team Project** notebook with your group (Starting on May 8th)
